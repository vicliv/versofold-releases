# VersoFold 0.1.0

First public Mac release — September 17, 2026.

VersoFold brings local LaTeX writing, a visual editor, PDF preview, a research library, citation checks, optional AI connections, collaboration, and paths to and from Overleaf into one desktop workspace.

## Download and install

- **Requirements:** Apple silicon Mac running macOS 13 or later.
- Download `VersoFold-0.1.0-arm64.dmg` below, open it, and drag VersoFold to Applications.
- Launch VersoFold from Applications. The first launch prepares bundled writing tools and can take a little longer.
- The app is signed with a Developer ID Application certificate and notarized by Apple.

**DMG SHA-256:** `e972849c3fd0355cc2675240bd5f29e01275b7d428678b4f0eb4e58a645e04f2`

The ZIP, blockmaps, and `latest-mac.yml` are published alongside the DMG for the desktop updater. The app checks for newer stable releases and lets you choose when to download and install them.
