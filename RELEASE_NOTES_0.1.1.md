# VersoFold 0.1.1

September 18, 2026 · macOS 13 or later · Apple silicon and Intel

Choose the DMG for your Mac below, then drag VersoFold to Applications. Both builds are signed and Apple-notarized.

## What’s new

- An update button appears in the home screen and editor when a newer version is available.
- Save your Overleaf Git token in Settings, and use Tab to complete suggested Git URLs.
- Review references flagged for human verification: inspect the agent’s limitations and open questions, edit the BibTeX entry, and validate it.
- Report a bug inside the app. Reports are stored privately and notify the maintainer by email; no project files or logs are attached automatically.
- More room for editor comments, a refreshed dark appearance, and clearer VersoFold branding.
- A small, optional coffee prompt after creating a fourth workspace, with a donation link in the app.
